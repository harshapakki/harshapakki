### Two roles, different instincts

**As an SDE** I ship inside a team. Feature work through enterprise review, versioned releases other
teams depend on, 68 tests on a mobile app I authored alone, 111 on a platform tool, and the paved
road underneath it, dev containers and release pipelines to an artifact registry.

**As an FDE** I am the whole team. Learn the domain from the people doing the work, model what they
actually do, then own requirements, build, auth, CI/CD, containers and monitoring. Then leave
runbooks and one-click paths so the customer keeps going without me.
